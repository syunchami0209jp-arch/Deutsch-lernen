第1課 修正版 v5

今回の修正
- 独日カード終了時は「0 / 0 正解」ではなく「完了」と表示。
- 独日カードで男性弱変化名詞（N-Deklination）の語には、その旨を明記。
- 定冠詞を通常伴わない国名（Deutschland）は、定冠詞問題で「通常定冠詞なし」を正解として出題。
- Name の複数形4択の誤答を Name から作った誤った形に修正。
- 間違えた問題を後で正解した場合、その問題を「間違えた問題だけ復習」から自動削除。
- 既存の questionContext は表示しない。
- 独日カードの矢印キー・Enterキー操作、ボタン位置固定を維持。

第2課以降
- 男性弱変化名詞は grammarNote を指定すると独日カードに表示できます。
- 定冠詞なしの名詞・国名は noArticle: true を指定すると「通常定冠詞なし」が正解になります。
- 複数形4択は pluralDistractors を指定すれば、その名詞自身から作った誤答を設定できます。
今回変更したファイル
1. app.js.txt → GitHubの app.js に貼り付け
2. index.html.txt → GitHubの index.html に貼り付け
3. style.css.txt → GitHubの style.css に貼り付け

data.js は今回変更不要です。

今回の主な変更
- 間違えた問題を「問題形式ごと」に記録。正解した形式だけ復習リストから削除。
- 未回答の問題は間違いとして登録されない。
- テスト終了画面に、今回間違えた単語・訳・軽い解説を表示。
- 「間違えた問題だけ復習」は、実際に間違えた形式だけを表示。独日カードは復習対象にしない。
- 独日カードに☆マイ辞書ボタンを追加。
- 登録した単語だけを使って練習できる「マイ辞書」を追加。
- マイ辞書では登録語について、カテゴリーごとの利用可能な練習形式を選べる。
- 旧形式の deutschQuestWrong がIDだけの配列だった場合、形式が分からないため新仕様へ誤変換せずリセットする。

注意
GitHubで既存ファイルを編集するときは、ファイル名は .html / .js / .css のままにしてください。

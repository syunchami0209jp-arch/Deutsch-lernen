## 動詞を追加する方法

`verbs.js` の `verbData` の中に、次のようなオブジェクトを1つ追加します。

{
  "id": "v-neues-verb",
  "infinitive": "neues Verb",
  "japanese": "日本語の意味",
  "du": "duの形",
  "er": "er/sie/esの形",
  "past": "過去形",
  "subj2": "接続法Ⅱ式",
  "participle": "過去分詞",
  "presentExample": "Du ___ ...",
  "pastExample": "Du ...",
  "subjExample": "Wenn ..., ___ ..."
}

つまり、問題データとプログラムを分離しています。
動詞を増やすときは基本的に `verbs.js` だけ編集すればOKです。

## 注意

「三基本形」は
不定詞 / 直説法過去 / 過去分詞

「直接法現在」は du の形を出題

「接続法Ⅱ式」は、写真のリストに載っている接続法Ⅱ式を出題

としてあります。
